# Verilumen Labs

Marketing site for Verilumen Labs, an AI-driven semiconductor test company. The page covers the product story, solutions, careers, and a contact form.

## Stack

- Vite
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lenis

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## What is on the page

- Home hero with the product video, muted by default, with a mute and unmute control
- Solutions, careers, and contact
- Footer with LinkedIn and Instagram, and a thin particle wave along the bottom
